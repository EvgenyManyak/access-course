Условия отбора — WHERE

= · IN · BETWEEN · LIKE · IS NULL / IS NOT NULL · AND · OR · NOT — каждый оператор фильтрует строки по-своему
Текст — в кавычках "так"; даты — между решётками #2024-03-01#

= точное равенство

Оставляет записи, у которых поле равно одному конкретному значению.
Пример
WHERE Category = "Электроника";
Categoryпроходит?
Электроника✓
Авто✗

IN список значений

Равенство любому из перечисленных значений — короткая замена цепочке OR.
Пример
WHERE Category IN ("Телефоны", "Компьютеры");
Categoryпроходит?
Телефоны✓ в списке
Компьютеры✓ в списке
Авто✗ нет

BETWEEN диапазон

Значение внутри отрезка — обе границы включаются в отбор.
Пример
WHERE UnitPrice BETWEEN 1000 AND 50000;
UnitPriceпроходит?
25000✓ внутри
750✗ меньше

LIKE шаблон

Сравнение по маске: * — любые символы в любом количестве (в Access), ? — один символ.
Пример
WHERE ProductName Like "*телефон*";
ProductNameпод маску?
Телефон стационарный✓
Стол компьютерный✗

IS NULL пустое значение

Находит записи, где поле вообще не заполнено (Null). Сравнение = Null не работает — только IS NULL.
Пример
WHERE CategoryGroup IS NULL;
CategoryGroupпроходит?
Null✓ пусто
"Электроника"✗

IS NOT NULL непустое значение

Обратно: отбирает только заполненные поля — полезно перед отчётами и выгрузками.
Пример
WHERE CategoryGroup IS NOT NULL;
CategoryGroupпроходит?
"Электроника"✓ заполнено
Null✗ пропущено

AND оба условия

Запись проходит, только если выполняются все условия одновременно.
Пример
WHERE Category = "Авто" AND UnitPrice < 10000;
записьусловия
Авто · 150000✗ цена
Авто · 8500✓ и то и то

OR хотя бы одно

Запись проходит, если выполняется хотя бы одно из условий.
Пример
WHERE Category = "Авто" OR Category = "Дом и мебель";
Categoryусловия
Авто✓ первое
Дом и мебель✓ второе
Электроника✗ ни одно

NOT отрицание

Отбирает записи, не удовлетворяющие условию — «всё, кроме…».
Пример
WHERE NOT Category = "Электроника";
CategoryNOT =
Электроника✗ исключена
Авто✓ проходит

Приоритет: NOT → AND → OR

Сначала выполняется NOT, затем AND, затем OR. Скобки меняют порядок и делают условие читаемым.
Пример со скобками
WHERE Category = "Авто"
   OR (Category = "Дом и мебель" AND UnitPrice < 10000);
без скобокошибка смысла
Дом и мебель · 25000✗ пройдёт?
со скобками✓ отсеется
