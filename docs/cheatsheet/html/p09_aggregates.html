Итоговые функции и группировка

Count · Sum · Avg · Min · Max · GROUP BY · HAVING — от таблицы записей к итоговой таблице
Итог по строкам делает одна функция — вместо ручного подсчёта

Count количество строк

Count(*) считает все строки выборки; Count(поле) — только заполненные (без Null).
Синтаксис и пример
SELECT Count(*) AS Количество
FROM Products;

Sum · Avg сумма и среднее

Sum складывает значения столбца, Avg считает среднее. Работают только с числами и деньгами.
Синтаксис и пример
SELECT Sum(UnitPrice) AS Сумма,
       Avg(UnitPrice) AS СредняяЦена
FROM Products;
Результат: Сумма 30700 и СредняяЦена 10233,33 — итог по всей таблице разом.

Min · Max минимум и максимум

Крайние значения столбца: самая дешёвая и дорогая позиция, первая и последняя дата.
Синтаксис и пример
SELECT Min(UnitPrice) AS Минимум,
       Max(UnitPrice) AS Максимум
FROM Products;
Результат: вилка цен 800 … 25000 — сразу видно разброс ассортимента.

GROUP BY группировка

Делит строки на группы по значению поля и считает агрегат для каждой группы отдельно.
Синтаксис и пример

HAVING фильтр по группам

WHERE отбирает строки до группировки, HAVING — уже готовые группы по значению агрегата.
Синтаксис и пример
SELECT Category, Avg(UnitPrice) AS СредняяЦена
FROM Products
GROUP BY Category
HAVING Avg(UnitPrice) > 10000;
