# Каталог sql — готовые примеры Access SQL

> 🚀 **Начало работы:** запросы этого каталога выполняются на подготовленной учебной базе ShopData.accdb с импортированным стартовым комплектом starter-data. Если база ещё не создана — пройдите страницу [../getting-started.html](../getting-started.html) (полный маршрут: установка, папки, доверенное расположение, импорт 6 CSV, ключи, связи) или короткий чек-лист [../starter-data/import-checklist.md](../starter-data/import-checklist.md).

Шесть файлов примеров к модулям 6–8: каждый оператор рассчитан на мини-датасет ShopData (12 заказов, 15 позиций, выручка без отменённых 3 025,50), все «Ожидаемые результаты» в комментариях пересчитаны по нему вручную.

## Как пользоваться

1. Откройте `ShopData.accdb` (модуль 01 / «Начало работы»).
2. Создание → Конструктор запросов → закройте окно «Добавление таблицы» → правый щелчок по вкладке → «Режим SQL».
3. Скопируйте **один оператор** (без строк `--` — комментарии в Access не работают) и выполните кнопкой «!».
4. Сверьте результат с комментарием «Ожидаемый результат» над оператором.

## Файлы

| Файл | Тема | Когда |
|---|---|---|
| `select-examples.sql` | TOP N, WHERE, BETWEEN, IN, Like, Is Null, IIF/FORMAT, DISTINCT/DISTINCTROW | Модули 6–7 |
| `joins.sql` | INNER/LEFT/RIGHT JOIN, self-join, UNION, анти-соединения, декартово произведение | Модуль 7 |
| `aggregate-queries.sql` | GROUP BY, SUM/AVG/MIN/MAX, ROUND, HAVING | Модуль 8 |
| `parameter-queries.sql` | PARAMETERS, диалоги ввода, BETWEEN по датам | Модуль 8 |
| `crosstab-queries.sql` | TRANSFORM…PIVOT, фиксированные столбцы IN, итоги | Модуль 8 |
| `action-queries.sql` | UPDATE, DELETE с каскадом, INSERT INTO, SELECT INTO, откаты | Модуль 8 |

Осторожно: `action-queries.sql` меняет данные — перед ним делайте копию базы в `backup\` (см. «Начало работы», шаг 14).
