SELECT * все поля

Звёздочка выбирает все столбцы таблицы — быстрый просмотр целиком.
Синтаксис
SELECT * FROM таблица;
Пример
SELECT * FROM Products;
Результат: все строки и все столбцы Products без фильтрации и сортировки.

SELECT отдельные поля

Перечисление столбцов через запятую оставляет только нужные поля — запрос быстрее и понятнее.
Синтаксис
SELECT поле1, поле2 FROM таблица;
Пример
SELECT ProductName, UnitPrice FROM Products;
Результат: два столбца ProductName и UnitPrice; столбец ID в вывод не попадает.

DISTINCT без повторов

Убирает дубликаты из результата: каждая комбинация значений выводится один раз.
Синтаксис
SELECT DISTINCT поле FROM таблица;
Пример
SELECT DISTINCT Category FROM Products;

AS псевдоним столбца

Задаёт заголовок столбца в результате — своё имя для поля или выражения.
Синтаксис
SELECT поле AS псевдоним FROM таблица;
Пример
SELECT ProductName AS Товар FROM Products;
Результат: данные те же, но столбец подписан «Товар» — удобно для выгрузок и отчётов.

ORDER BY сортировка

Сортирует результат: ASC — по возрастанию (по умолчанию), DESC — по убыванию.
Синтаксис
ORDER BY поле [ASC | DESC];
Пример — по убыванию цены
SELECT ProductName, UnitPrice
FROM Products ORDER BY UnitPrice DESC;

TOP первые записи

Возвращает заданное число первых строк — почти всегда вместе с ORDER BY, иначе строки непредсказуемы.
Синтаксис
SELECT TOP N поля FROM таблица ORDER BY ...;
Пример — топ-2 дорогих товара
SELECT TOP 2 ProductName, UnitPrice
FROM Products ORDER BY UnitPrice DESC;

Порядок частей запроса SELECT

Access выполняет части запроса именно в этом порядке: FROM находит таблицу → WHERE отбирает строки → GROUP BY группирует → HAVING фильтрует группы → ORDER BY сортирует → SELECT возвращает поля.
