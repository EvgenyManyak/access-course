# Словарь данных ShopData (data-dictionary)

Сквозной датасет курса. Основной источник — Kaggle [Olist Brazilian E-commerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (CC BY-NC-SA 4.0). Учебные поля, отсутствующие в оригинале (`CustomerName`, `EmployeeName`, `ManagerID`, `Quantity`, `HireDate`, `Segment`), добавлены заранее, чтобы студент не тратил время на ручной ввод.

Соглашение об именах объектов Access: таблицы — без префикса; запросы `qry_`, формы `frm_`, подчинённые формы `sfrm_`, отчёты `rpt_`, макросы `mcr_`.

## Customers — покупатели

Источник: `olist_customers_dataset.csv` (+ синтетические имена).

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `CustomerID` | Короткий текст (32) | Первичный ключ | Идентификатор покупателя из датасета |
| `CustomerName` | Короткий текст (100) | — | Учебное имя для форм и отчётов |
| `ZipCodePrefix` | Короткий текст (5) | Обычный индекс | Префикс почтового индекса. **Текст!** Ведущие нули (01310) теряются в числовом типе |
| `City` | Короткий текст (80) | Обычный индекс | Город доставки |
| `State` | Короткий текст (2) | Обычный индекс | Код штата (SP, RJ, MG, …) |
| `Segment` | Короткий текст (20) | Условие на значение: Retail / Wholesale / VIP | Учебный сегмент для отчётов |

## Categories — справочник категорий

Источник: `product_category_name_translation.csv` (для мини-датасета — 5 строк).

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `CategoryID` | Счётчик | Первичный ключ | Суррогатный числовой ключ |
| `CategoryName` | Короткий текст (64) | Уникальный индекс | Оригинальное название (португальский): `cama_mesa_banho` |
| `CategoryNameEn` | Короткий текст (64) | Обычный индекс | Название на английском: `bed_bath_table` |

## Products — товары

Источник: `olist_products_dataset.csv` (+ синтетические названия). В учебной модели добавлено поле `UnitPrice` — ориентировочная цена для упражнений форм (в оригинале цена живёт в позициях заказов).

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `ProductID` | Короткий текст (32) | Первичный ключ | Идентификатор товара |
| `ProductName` | Короткий текст (120) | — | Учебное название для интерфейса |
| `CategoryID` | Числовой (длинное целое) | Внешний ключ → Categories | Ссылка на категорию |
| `UnitPrice` | Денежный | Условие на значение: >=0 | Ориентировочная цена, Р$ |
| `WeightG` | Числовой (длинное целое) | — | Вес, граммы; возможны пропуски |
| `LengthCm`, `HeightCm`, `WidthCm` | Числовой (целое) | — | Габариты упаковки, см |

## Employees — сотрудники (менеджеры заказов)

Основа: `olist_sellers_dataset.csv` (поля синтетические). В мини-датасете — 6 сотрудников.

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `EmployeeID` | Счётчик | Первичный ключ | Суррогатный ключ |
| `EmployeeName` | Короткий текст (100) | — | Учебное имя сотрудника |
| `SellerID` | Короткий текст (32) | Уникальный индекс | Исходный идентификатор продавца |
| `Role` | Короткий текст (20) | Список: Менеджер / Оператор / Аналитик | Роль |

| `HireDate` | Дата/время | Обычный индекс | Дата приёма на работу |

## Orders — заказы

Источники: `olist_orders_dataset.csv` (+ синтетический `ManagerID`).

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `OrderID` | Короткий текст (32) | Первичный ключ | Идентификатор заказа |
| `CustomerID` | Короткий текст (32) | Внешний ключ → Customers | Кто купил |
| `ManagerID` | Числовой (длинное целое) | Внешний ключ → Employees | Закреплённый менеджер |
| `OrderStatus` | Короткий текст (20) | Обычный индекс | delivered / shipped / canceled / processing / unavailable / invoiced / approved / created |
| `OrderDate` | Дата/время | Обычный индекс | Момент покупки (`order_purchase_timestamp`) |
| `DeliveredDate` | Дата/время | — | Факт доставки; для недоставленных — пусто (NULL) |
| `EstimatedDate` | Дата/время | — | Ожидавшаяся дата доставки |

## OrderDetails — позиции заказов

Источник: `olist_order_items_dataset.csv`.

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `OrderDetailID` | Счётчик | Первичный ключ | Суррогатный ключ строки |
| `OrderID` | Короткий текст (32) | Внешний ключ → Orders; составной индекс с ProductID | Ссылка на заказ |
| `ProductID` | Короткий текст (32) | Внешний ключ → Products | Ссылка на товар |
| `Quantity` | Числовой (целое) | По умолчанию 1 | Количество (в Olist строка = 1 позиция) |
| `UnitPrice` | Денежный | Условие на значение: >=0 | Цена единицы в момент продажи (`price`) |
| `FreightValue` | Денежный | Условие на значение: >=0 | Стоимость доставки позиции (`freight_value`) |
| `ShippingLimitDate` | Дата/время | — | Предельный срок отгрузки продавцом |

## Calendar — календарь

Генерируется в Access (макрос/VBA) или импортируется готовым CSV. Нужен для перекрёстных запросов и подписей периодов.

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `CalDate` | Дата/время | Первичный ключ | Дата без времени |
| `CalYear`, `CalQuarter`, `CalMonth` | Числовой (целое) | Обычные индексы | Год, квартал, номер месяца |
| `MonthName`, `MonthYear` | Короткий текст | — | «Март», «мар 2017» — подписи для перекрёстных запросов |
| `WeekDay` | Числовой (целое) | — | День недели 1–7 |
| `IsWeekend` | Логический | — | Признак выходного |

## Служебные объекты

| Объект | Назначение |

## Связи модели (6 связей)

| Связь | Тип | Целостность | Особенности |
|---|---|---|---|
| Categories → Products | 1:М | включена | по `CategoryID` |
| Customers → Orders | 1:М | включена | по `CustomerID` |
| Employees → Orders | 1:М | включена | по `ManagerID` |
| Orders → OrderDetails | 1:М | включена | + **каскадное удаление** (тестовая очистка архива) |
| Products → OrderDetails | 1:М | включена | по `ProductID` |
| Calendar → Orders | 1:М | включена | по `CalDate = OrderDate` |
