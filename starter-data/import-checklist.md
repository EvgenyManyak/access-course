# Чек-лист импорта стартового комплекта (import-checklist)

Пошаговый маршрут: шесть CSV из этой папки → готовая база ShopData.accdb с ключами, связями и проверенными числами. Время — 15–20 минут. Выполняйте пункты по порядку и отмечайте галочки (страница «Начало работы» хранит тот же чек-лист в браузере).

## 1. Подготовка (5 минут)

- [ ] Access установлен (2007–2016; курс показан на 2016). Проверка: Файл → Учётная запись → «О Access».
- [ ] Создана рабочая папка `C:\Courses\ShopData\` с подпапками `import\`, `base\`, `export\`, `backup\`.
- [ ] Папка `C:\Courses\ShopData\` добавлена в доверенные расположения (Файл → Параметры → Центр управления безопасностью → Параметры центра… → Доверенные расположения → Добавить новое расположение). Без этого Access блокирует макросы и части импорта.
- [ ] Шесть CSV из этой папки скопированы в `import\` (или путь к ним известен).
- [ ] Проверка кодировки: откройте `customers.csv` в Блокноте — в начале файла может быть незаметный символ BOM, кириллица читается нормально (наши файлы — UTF-8 с BOM), строки разделены переводами строк.

## 2. Создание базы

- [ ] Access → «Пустая база данных» → имя файла `ShopData.accdb` → значок папки → выбрать `C:\Courses\ShopData\base\` → «Создать».
- [ ] Закройте пустую «Таблицу1» (правый щелчок по вкладке → Закрыть), не сохраняя.

## 3. Импорт шести файлов (общая процедура)

Порядок импорта: **categories → products → customers → employees → orders → order-details** (справочники раньше фактов — удобнее проверять связи).

Для каждого файла:

1. **Внешние данные → Новый источник данных → Из файла → Текстовый файл** → выберите файл → «Импортировать исходные данные в новую таблицу» → ОК.
2. Мастер: «С разделителями…» → Далее.
3. Разделитель — **запятая**, ограничитель текста — `"`, кодировка — **Юникод (UTF-8)**.
4. Нажмите **«Дополнительно…»** → порядок дат **ГМД** (файлы хранят даты как 2017-03-15) → ОК.
5. Проверьте по образцу из README.md, что значения колонок не съехали → Далее.
6. Задайте поля и типы по таблице ниже → Далее.
7. «Самостоятельно задать первичный ключ» → выберите ключевое поле (таблица ниже) → Далее.
8. Имя таблицы — по словарю курса: **Categories, Products, Customers, Employees, Orders, OrderDetails** (для order-details.csv исправьте предложенное Access имя на OrderDetails) → Готово. Окно сохранения шагов импорта можно закрыть (спецификации пригодятся в модуле 13).

### Поля и типы по файлам

| Файл | Ключ | Обязательные типы (ловушки) |
|---|---|---|
| categories.csv | CategoryID | CategoryID — Числовой (длинное целое)*; оба имени — Короткий текст (64) |
| products.csv | ProductID | UnitPrice — **Денежный**; CategoryID — Числовой; WeightG — Числовой (длинное целое); габариты — Числовой (целое) |
| customers.csv | CustomerID | ZipCodePrefix — **Короткий текст (5)**, не число (ведущий ноль!); State — текст (2) |
| employees.csv | EmployeeID | EmployeeID — Числовой; Role — текст; HireDate — **Дата/время** |
| orders.csv | OrderID | ManagerID — Числовой; три даты — **Дата/время** (пустые DeliveredDate — это NULL, так и должно быть) |
| order-details.csv | OrderDetailID | Quantity — Числовой (целое); UnitPrice, FreightValue — **Денежный**; ShippingLimitDate — Дата/время |

\* Значения ключей-счётчиков (1–5, 1–6, 1–15) уже лежат в файлах: оставьте поле «Числовым» с первичным ключом — на задания курса это не влияет. Если хотите точную копию схемы со «Счётчиком» — импортируйте без этих колонок и добавьте счётчик в конструкторе (подробно — модуль 02).

## 4. Проверка импорта (сразу после каждого файла)

- [ ] Откройте таблицу в режиме таблицы и сверьте первую строку с образцом в README.md.
- [ ] Количество строк: Categories **5**, Products **8**, Customers **8**, Employees **6**, Orders **12**, OrderDetails **15** (счётчик записей внизу окна).
- [ ] `ZipCodePrefix` показывает 01310 с нулём; `UnitPrice` выровнен вправо (число/деньги); `OrderDate` — настоящая дата, а не текст слева.
- [ ] Тестовый запрос (Создание → Конструктор запросов → закрыть окно таблиц → Режим SQL):

```sql
SELECT TOP 5 CustomerID, CustomerName, City, Segment
FROM Customers
ORDER BY CustomerID;
```

Ожидается 5 строк: C-0001 Ana Ribeiro … C-0005 Elena Costa (эталон в модуле 01). Это первый запрос курса — если он совпал, импорт Customers сделан верно.

## 5. Первичные ключи

- [ ] Для каждой таблицы: конструктор → выделить ключевое поле → «Ключевое поле». Поля — в таблице выше. После установки Access запретит дубли и пустые значения ключа.
- [ ] Быстрая проверка: попытайтесь ввести второй заказ `O-10001` в Orders — Access должен отклонить запись («Изменения не были успешно внесены…»).

## 6. Связи

Схема данных (Работа с базами данных → Схема данных), добавьте все шесть таблиц и связи с «Обеспечением целостности данных»:

- [ ] Categories → Products (CategoryID)
- [ ] Customers → Orders (CustomerID)
- [ ] Employees → Orders (ManagerID)
- [ ] Orders → OrderDetails (OrderID) + **«Каскадное удаление связанных записей»**
- [ ] Products → OrderDetails (ProductID)
- [ ] Calendar → Orders добавите в модуле 04, когда календарь будет создан.

Проверка ссылочной целостности: попытайтесь в Orders ввести `ManagerID = 9` — Access должен отклонить значение («…требуются связанные записи в таблице Employees»). Затем верните корректного менеджера (для O-10001 это 2 — Pedro Santos).

## 7. Итоговая самопроверка базы

- [ ] `SELECT SUM(UnitPrice) FROM Products;` → **1423.10**
- [ ] `SELECT COUNT(*) FROM Orders;` → **12**; `SELECT COUNT(*) FROM OrderDetails;` → **15**
- [ ] Запрос выручки без отменённых (эталон модуля 08):

```sql
SELECT c.CategoryNameEn,
       ROUND(SUM(od.UnitPrice * od.Quantity), 2) AS Выручка
FROM Categories AS c
INNER JOIN (Products AS p
            INNER JOIN (Orders AS o
                        INNER JOIN OrderDetails AS od
                        ON o.OrderID = od.OrderID)
            ON p.ProductID = od.ProductID)
ON c.CategoryID = p.CategoryID
WHERE o.OrderStatus <> "canceled"
GROUP BY c.CategoryNameEn
ORDER BY SUM(od.UnitPrice * od.Quantity) DESC;
```

Ожидается 5 строк: bed_bath_table 769.50 · computers_accessories 746.50 · furniture_decor 640.00 · health_beauty 631.50 · automotivo 238.00; итого **3025.50**.

- [ ] Резервная копия: закройте базу, скопируйте `base\ShopData.accdb` в `backup\ShopData_ГГГГ-ММ-ДД.accdb`.

Если все пункты отмечены — база готова к модулю 01 и ко всему курсу.

## Типичные ошибки и решения

| № | Симптом | Причина | Решение |
|---|---|---|---|
| 1 | Мастер показывает кракозябры вместо «Набор постельного белья» | Выбрана не та кодировка | Вернитесь в мастере к шагу кодировки и выберите **Юникод (UTF-8)**; файлы комплекта хранятся в UTF-8 с BOM |
| 2 | Даты стали текстом или перепутаны день/месяц (03/15/2017) | Порядок дат не указан | Удалите таблицу, импортируйте заново: «Дополнительно…» → порядок дат **ГМД** |
| 3 | ZipCodePrefix = 1310, ноль потерян | Поле распознано числом | Импортируйте заново, назначьте полю тип «Короткий текст (5)» на шаге выбора типов; либо UPDATE `SET ZipCodePrefix = Format([ZipCodePrefix],"00000")` — но лучше переимпорт |
| 4 | Цены импортировались текстом (выровнены влево), в числовом поле пусто | На русской Windows десятичный разделитель — запятая, а в файлах точка | Вариант А: импортируйте поле как текст, добавьте новое поле «Денежный» и выполните `UPDATE Products SET UnitPriceNum = CCur(Val([UnitPrice]))` — функция Val всегда читает точку независимо от локали. Вариант Б: переимпорт с ручным типом «Денежный» на шаге мастера — Access разберёт значения по локали системы |
| 5 | «Индекс или ключ не уникален / повторяющиеся значения» при установке ключа | В поле есть дубли (обычно импортировали файл дважды) | Удалите таблицу и импортируйте один раз; перед импортом проверяйте, что таблицы с таким именем нет |
| 6 | При создании связи Access пишет «Нарушение целостности данных» | В фактах есть коды, которых нет в справочнике | В комплекте таких нет: проверьте, что импортированы все 6 файлов и типы связываемых полей совпадают (текст↔текст, число↔число) |
| 7 | В Orders пусто в DeliveredDate у O-10005/O-10006/O-10010 | Это не ошибка | Пусто = NULL: заказы ещё не доставлены (shipped), отменены (canceled), в обработке (processing). Модуль 07 учит проверять их через `Is Null` |
| 8 | Access показывает «Возможные проблемы безопасности. Макросы отключены» | База вне доверенной папки | Файл → Параметры → Центр управления безопасностью → Доверенные расположения → добавьте `C:\Courses\ShopData\` (шаг 1 чек-листа) |
