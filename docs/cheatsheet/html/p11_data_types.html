Типы данных Access

Короткий текст · Длинный текст · Числовой · Денежный · Дата и время · Счётчик · Да/Нет · Вложение
Название в Конструкторе ↔ SQL-тип в CREATE TABLE

Короткий текст

До 255 символов: названия, артикулы, категории. Размер задаётся свойством поля.
ProductName TEXT(100)
-- пример значения: "Стол"
Пример поля: ProductName TEXT(100) — см. блок 10 про размер и проверку.

Длинный текст

Текст без ограничения длины (Memo): описания, комментарии, примечания.
Description LONGTEXT
-- пример: описание товара
-- на несколько абзацев
Пример поля: Description LONGTEXT; в группировках и JOIN участвует редко.

Числовой

Размеры поля: LONG (целое), DOUBLE (дробное), INTEGER и другие — под задачу.
Quantity LONG
UnitPriceNum DOUBLE
-- пример значения: 25
Пример поля: Quantity LONG; ключевые связи с AUTOINCREMENT — только LONG (блоки 1 и 5).

Денежный

CURRENCY — фиксированные 4 знака после запятой: точные суммы без ошибок округления.
UnitPrice CURRENCY
-- пример значения: 25 000,50
Пример поля: UnitPrice CURRENCY; текст в деньги превращает CCur (блок 6).

Дата и время

DATETIME хранит дату и время разом; литералы в SQL — между решётками #...#.
OrderDate DATETIME
-- пример: #2024-03-01#
Пример поля: OrderDate DATETIME; функции дат — блок 8.

Счётчик

AUTOINCREMENT: Access сам присваивает 1, 2, 3… — идеальный первичный ключ.
ID AUTOINCREMENT PRIMARY KEY
-- значения: 1, 2, 3, ...
Пример поля: ID AUTOINCREMENT PRIMARY KEY; на него ссылается FK типа LONG.

Да/Нет

Логический флажок: Да (True, −1) или Нет (False, 0) — активность, оплата, отметки.
IsActive YESNO
-- пример: WHERE IsActive = True
Пример поля: IsActive YESNO; в WHERE пишут = True или = False.

Вложение

Файлы (картинки, PDF) внутри записи; через SQL DDL не создаётся — только в Конструкторе.
-- в CREATE TABLE недоступен,
-- добавляется в Конструкторе
-- пример: скан счёта в записи
Пример: поле СканСчёта с вложенным PDF; в запросах участвует как ссылка на файл.

Как выбрать тип: короткая шпаргалка выбора

Результат: правильный тип с самого начала избавляет от пересоздания полей (ALTER COLUMN, блок 1) и ошибок округления.
