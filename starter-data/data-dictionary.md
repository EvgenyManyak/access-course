# Словарь данных стартового комплекта (data-dictionary)

Полное описание шести таблиц мини-датасета ShopData: поля, типы Access, ключи, связи и назначение. Таблица Calendar описана в `../datasets/data-dictionary.md`. Соглашение об именах объектов: таблицы — без префикса; запросы `qry_`, формы `frm_`, подчинённые формы `sfrm_`, отчёты `rpt_`, макросы `mcr_`.

## Categories — справочник категорий (5 строк)

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `CategoryID` | Числовой (длинное целое)* | Первичный ключ | Числовой ключ категории: 1–5 |
| `CategoryName` | Короткий текст (64) | Уникальный индекс | Оригинальное название (португальский): `cama_mesa_banho` |
| `CategoryNameEn` | Короткий текст (64) | Обычный индекс | Название на английском: `bed_bath_table`; используется в перекрёстных запросах модуля 08 |

\* В файлах модуля 02 поле создаётся типом «Счётчик» — при импорте CSV оставьте «Числовой», значения 1–5 уже в файле. На задания курса это не влияет.

Данные: cama_mesa_banho / bed_bath_table; beleza_saude / health_beauty; informatica_acessorios / computers_accessories; moveis_decoracao / furniture_decor; automotivo / auto.

## Products — товары (8 строк)

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `ProductID` | Короткий текст (32) | Первичный ключ | Код товара: P-1001 … P-5001. **Текст!** Код сравнивают, а не складывают |
| `ProductName` | Короткий текст (120) | — | Название для интерфейса и отчётов |
| `CategoryID` | Числовой (длинное целое) | Внешний ключ → Categories | Ссылка на категорию (1–5) |
| `UnitPrice` | Денежный | Условие на значение: >=0 | Ориентировочная цена, Р$; в CSV — с точкой |
| `WeightG` | Числовой (длинное целое) | — | Вес, граммы: 900, 350, 120, 80, 100, 200, 2500, 1200 |
| `LengthCm`, `HeightCm`, `WidthCm` | Числовой (целое) | — | Габариты упаковки, см |

Данные: P-1001 Набор постельного белья 2-сп (кат. 1, 189.90); P-1002 Подушка ортопедическая (1, 129.90); P-2001 Крем для лица SPF30 (2, 89.90); P-2002 Витамин C 1000 мг (2, 45.50); P-3001 Беспроводная мышь (3, 149.00); P-3002 USB-хаб 4 порта (3, 59.90); P-4001 Торшер деревянный (4, 640.00); P-5001 Насос для шин (5, 119.00).

## Customers — покупатели (8 строк)

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `CustomerID` | Короткий текст (32) | Первичный ключ | Код покупателя: C-0001 … C-0008 |
| `CustomerName` | Короткий текст (100) | — | Имя для форм и отчётов |
| `ZipCodePrefix` | Короткий текст (5) | Обычный индекс | Префикс почтового индекса. **Текст!** Ведущие нули (01310) теряются в числовом типе |
| `City` | Короткий текст (80) | Обычный индекс | Город доставки (в датасете — строчными: sao paulo) |
| `State` | Короткий текст (2) | Обычный индекс | Код штата: SP, RJ, MG, PR, PE, RS, BA, AM |
| `Segment` | Короткий текст (20) | Условие на значение: Retail / Wholesale / VIP | Учебный сегмент для отчётов |

## Orders — заказы (12 строк)

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `OrderID` | Короткий текст (32) | Первичный ключ | Код заказа: O-10001 … O-10012 |
| `CustomerID` | Короткий текст (32) | Внешний ключ → Customers | Кто купил |
| `ManagerID` | Числовой (длинное целое) | Внешний ключ → Employees | Закреплённый менеджер (1–6) |
| `OrderStatus` | Короткий текст (20) | Обычный индекс | delivered (9), shipped (O-10005), canceled (O-10006), processing (O-10010) |
| `OrderDate` | Дата/время | Обычный индекс | Момент покупки, 2017-03-15 … 2018-06-12 |
| `DeliveredDate` | Дата/время | — | Факт доставки; у O-10005/O-10006/O-10010 — пусто (NULL) |
| `EstimatedDate` | Дата/время | — | Ожидавшаяся дата доставки |

Распределение по менеджерам (для проверки RIGHT JOIN модуля 07): Ana Souza — 3, Pedro Santos — 3, Maria Oliveira — 3, Lucas Ferreira — 2 (включая отменённый O-10006), Rafael Lima — 1, Julia Pereira — 0. Сроки доставки девяти delivered-заказов: 9, 13, 10, 9, 13, 13, 11, 12, 12 дней (сумма 102, среднее ≈ 11,3).

## OrderDetails — позиции заказов (15 строк)

| Поле | Тип Access | Ключ/индекс | Назначение |
|---|---|---|---|
| `OrderDetailID` | Числовой (длинное целое)* | Первичный ключ | Номер строки: 1–15, в хронологии заказов |
| `OrderID` | Короткий текст (32) | Внешний ключ → Orders; каскадное удаление | Ссылка на заказ |
| `ProductID` | Короткий текст (32) | Внешний ключ → Products | Ссылка на товар |
| `Quantity` | Числовой (целое) | По умолчанию 1 | Количество: 1–4 шт. |
| `UnitPrice` | Денежный | Условие на значение: >=0 | Цена единицы в момент продажи |
| `FreightValue` | Денежный | Условие на значение: >=0 | Стоимость доставки позиции |
| `ShippingLimitDate` | Дата/время | — | Предельный срок отгрузки продавцом |

\* См. примечание к CategoryID.

Раскладка позиций: O-10001 — строки 1–2 (P-1001 ×1; P-2001 ×2); O-10002 — 3 (P-3001 ×1); O-10003 — 4–5 (P-4001 ×1; P-2002 ×3); O-10004 — 6 (P-1002 ×2); O-10005 — 7 (P-3002 ×4); O-10006 — 8 (P-2001 ×1, отменён); O-10007 — 9–10 (P-5001 ×2; P-2002 ×1); O-10008 — 11 (P-1001 ×1); O-10009 — 12 (P-3001 ×2); O-10010 — 13 (P-3002 ×1); O-10011 — 14 (P-2001 ×3); O-10012 — 15 (P-1002 ×1).

## Связи модели (5 связей стартового комплекта + 1)

| Связь | Тип | Целостность | Особенности |
|---|---|---|---|
| Categories → Products | 1:М | включена | по `CategoryID` |
| Customers → Orders | 1:М | включена | по `CustomerID` |
| Employees → Orders | 1:М | включена | по `ManagerID` = EmployeeID |
| Orders → OrderDetails | 1:М | включена | + **каскадное удаление** (тест очистки в модуле 08) |
| Products → OrderDetails | 1:М | включена | по `ProductID` |
| Calendar → Orders | 1:М | включена | по `CalDate = OrderDate` — **после** создания Calendar (модуль 04) |
