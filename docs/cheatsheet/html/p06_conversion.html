Преобразование типов и вычисления

Nz · IsNull · Val · CCur · CInt / CLng · CDate · Replace · IIf — схема «исходное значение → функция → результат»
В русской локали Access аргументы разделяются ;

Nz замена Null значением

Возвращает поле, а если оно Null — подставляет запасное значение. Спасает суммы и конкатенации.
Синтаксис и пример
Nz([UnitPrice]; 0)
Результат: Nz([UnitPrice];0)*1.2 посчитается даже там, где цена не заполнена.

IsNull проверка на Null

Возвращает Да/True, если поле пустое. В отличие от = Null работает всегда.
Синтаксис и пример
IsNull([CategoryGroup])
Результат: WHERE IsNull([CategoryGroup]) — то же, что WHERE CategoryGroup IS NULL.

Val извлечение числа из текста

Читает число из начала текстовой строки; запятую заранее меняют на точку через Replace.
Синтаксис и пример
Val(Replace([UnitPrice]; ","; "."))
Результат: текстовая цена стала числом — с ней работают сравнения и Sum/Avg.

CCur приведение к денежному типу

Превращает число или текст в денежное значение — убирает ошибки округления при расчётах.
Синтаксис и пример
CCur(Val([UnitPrice]))
Результат: значение готово для денежного поля и точных сумм в отчётах.

CInt · CLng целые числа

CInt — целое в диапазоне Integer, CLng — длинное целое для больших значений и ключей.
Синтаксис и пример
CInt([Quantity])    CLng([ID])
Результат: 12.7 → 13 (округление к чётному банкирское: 12.5 → 12).

CDate приведение к дате

Превращает текст или число в настоящую дату — после этого работают Year, DateAdd, DateDiff.
Синтаксис и пример
CDate("01.03.2024")
Результат: строка стала датой; в SQL литералы дат записываются между #.

Replace замена символов

Заменяет в строке все вхождения одной подстроки другой — чистка дефисов, разделителей, кавычек.
Синтаксис и пример
Replace([ProductName]; "-"; " ")
Результат: каждое вхождение «-» заменено пробелом; поиска и замены по таблице это не меняет.

IIf условное значение

Мгновенное «если… то… иначе» прямо в выражении: условие; значение если Да; значение если Нет.
Синтаксис и пример
IIf([UnitPrice] > 10000; "Дорого"; "Недорого")
Результат: для цены 25000 выражение вернёт Дорого; для 1200 — Недорого.

Цепочка очистки денежного значения — текст → Val → CCur → денежное поле

Каждый шаг превращает «грязное» значение из выгрузки в тип, с которым Access умеет работать: сначала число, затем деньги.
