# Каталог datasets — данные курса ShopData

Этот каталог отвечает на вопрос «откуда данные» для всех заданий курса.

## Состав каталога

| Файл | Назначение |
|---|---|
| `kaggle-links.html` | Интерактивная страница с кликабельными ссылками Kaggle: основной датасет Olist, альтернативы Superstore и Online Retail (UCI), правила проверки ссылок и лицензий. Открывается из бокового меню учебника («Датасеты и ссылки Kaggle») |
| `data-dictionary.md` | Словарь данных: все 7 таблиц ShopData (поля, типы Access, ключи, индексы, источники), служебные объекты (staging, архив), 6 связей модели, эталонные контрольные числа |
| `import-instructions.md` | Три пути получения данных: A — Olist с Kaggle (основной), B — альтернативные датасеты с маппингом полей, C — мини-датасет без Kaggle (SQL-вставки); таблица типовых проблем импорта и финальный чек-лист |

## Коротко о данных

- **Основной датасет:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), 100 тыс. заказов 2016–2018, 9 CSV, лицензия CC BY-NC-SA 4.0. Дата проверки ссылки: 2026-09-15.
- **Модель курса:** Customers, Products, Categories, Employees, Orders, OrderDetails, Calendar — связи 1:М, ссылочная целостность, каскадное удаление для Orders → OrderDetails.
- **Мини-датасет:** 5 категорий, 8 товаров, 8 покупателей, 6 сотрудников, 12 заказов, 15 позиций — данные зашиты в SQL-примеры каталога `sql/`, поэтому все эталонные результаты упражнений воспроизводятся офлайн.

## Правила по датасетам (важно)

1. Файлы датасетов **не включаются** в репозиторий — только ссылки и инструкции. Это уважение к лицензиям Kaggle и весу репозитория.
2. Учебник распространяется по MIT, но сторонние датасеты под MIT не подпадают: соблюдайте лицензию каждого набора (страница Kaggle → раздел License).
3. Ссылки могут меняться: на каждой карточке указана дата проверки. Если ссылка не открывается — инструкция «Как проверять ссылки самостоятельно» внизу `kaggle-links.html`. Непроверенные ссылки помечаются флагом `TODO: VERIFY DATASET URL` и не публикуются кликабельными.

## Как обновить данные курса

1. Проверьте ссылки по инструкции из `kaggle-links.html`; обновите даты проверки на карточках.
2. Если состав файлов датасета изменился — поправьте маппинг в `import-instructions.md` (таблица «Файл Olist → таблица курса»).
3. Если изменились эталонные числа (например, вы решили пересобрать мини-датасет) — синхронизируйте три места: `data-dictionary.md`, SQL-файлы каталога `sql/`, тексты модулей (поиск по старым значениям, например «3 025,50»).
