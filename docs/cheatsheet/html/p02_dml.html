DML — добавление, изменение, удаление

INSERT INTO · UPDATE · DELETE — для каждого оператора сцена «данные до → действие → данные после»
Перед UPDATE и DELETE выполните SELECT с тем же WHERE

INSERT INTO одна запись

Добавляет в таблицу одну новую строку: список полей затем список значений.
Синтаксис
INSERT INTO таблица (поле1, поле2)
VALUES (значение1, значение2);
Пример — одно значение
INSERT INTO Products (ProductName, UnitPrice)
VALUES ("Стол", 25000);

INSERT INTO ... SELECT несколько записей

Копирует в таблицу сразу набор строк, отобранных запросом SELECT.
Синтаксис
INSERT INTO таблица_приёмник (список полей)
SELECT ... FROM ... [WHERE ...];
Пример — несколько значений (архивация)
INSERT INTO Products_Archive
SELECT * FROM Products
WHERE UnitPrice < 5000;

UPDATE изменить одно поле

Меняет значения полей у записей, отобранных условием WHERE. Без WHERE изменятся все строки!
Синтаксис
UPDATE таблица SET поле = значение
WHERE условие;
Пример — одно значение
UPDATE Products SET UnitPrice = 30000
WHERE ID = 1;

UPDATE несколько полей и выражения

В SET через запятую можно обновить сразу несколько полей — в том числе выражениями над другими полями.
Пример — несколько значений сразу
UPDATE Products
SET CategoryGroup = "Электроника",
    UnitPriceNum = CCur(Val(UnitPrice))
WHERE Category IN ("Телефоны", "Компьютеры");

DELETE удаление записей

Удаляет целиком строки, отобранные условием WHERE. Без WHERE удалятся все данные таблицы!
Синтаксис
DELETE FROM таблица WHERE условие;
Пример — одна или несколько записей
DELETE FROM Products WHERE ID = 1;

Порядок безопасного изменения

UPDATE и DELETE нельзя отменить в Access — сначала посмотрите, что попадёт под условие.
Схема безопасной проверки
Пример: для DELETE FROM Products WHERE ID = 1; сначала выполните SELECT * FROM Products WHERE ID = 1;
