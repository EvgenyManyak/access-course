8

Работа с датами

Date · Now · Year / Month / Day · DateAdd · DateDiff · Format — календарь, часы и временная шкала
Литералы дат в SQL — между решётками: #2024-03-01#

Date · Now сегодня; сегодня и время

Date() возвращает текущую дату без времени, Now() — дату со временем. Без аргументов.
Синтаксис и пример
Date()   Now()
Результат: значения вычисляются в момент запуска запроса — удобно для «просрочено ли?».

Year · Month · Day части даты

Выделяют из даты год, номер месяца и день — для группировки по периодам.
Синтаксис и пример ([OrderDate] = 15.01.2024)
Year([OrderDate])  Month([OrderDate])  Day([OrderDate])
Результат: из одной даты получаются три числа — строительные блоки для отчётов по периодам.

DateAdd прибавить интервал

Сдвигает дату на заданное число интервалов: "yyyy" — годы, "m" — месяцы, "d" — дни.
Синтаксис и пример
DateAdd("m"; 1; [OrderDate])
Результат: 15.01.2024 → 15.02.2024 — срок оплаты, гарантия, следующая поставка.

DateDiff разница между датами

Считает, сколько интервалов помещается между двумя датами: дней, месяцев, лет.
Синтаксис и пример
DateDiff("d"; [OrderDate]; Date())
Результат: 47 — возраст заказа в днях; с "m" и "yyyy" — возраст в месяцах и годах.

Format дата в текст по шаблону

Превращает дату в строку нужного вида — для выгрузок и подписей в отчётах.
Синтаксис и пример
Format([OrderDate]; "dd.mm.yyyy")
Результат: строка "15.01.2024"; шаблон "mm.yyyy" даёт метку периода "01.2024".

Даты в условиях WHERE

Литералы дат заключаются между решётками; диапазон — через BETWEEN или пару неравенств.
Примеры
WHERE OrderDate = #2024-01-15#
WHERE OrderDate BETWEEN #2024-01-01#
                 AND #2024-01-31#
OrderDateв январе?
#2024-01-15#✓
#2024-02-03#✗ вне диапазона
Результат: отбор заказов за день или за период; год и месяц удобно брать функциями Year/Month.

Практика: возраст и просрочка

DateDiff и IIf вместе превращают даты в бизнес-статусы прямо в запросе.
Пример — флаг просрочки
IIf(DateDiff("d"; [OrderDate]; Date()) > 30;
    "Просрочен"; "В работе")
OrderDateстатус
возраст 47 днейПросрочен
возраст 5 днейВ работе
Результат: каждому заказу присвоен статус по возрасту; порог 30 дней меняется одним числом.

Мини-календарь — как функции читают дату

Один и тот же лист календаря отвечает на три вопроса: какой год, какой месяц, какой день.
Результат: GROUP BY Year(...), Month(...) режет таблицу на периоды, Day() выделяет день внутри месяца.
